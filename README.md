## 口碑和几个真实的坑

App Store 上 TTime 的评分是 4.3/5。评论区和第三方测评里反复出现的词是“快”，打开快，出译文也快。有人把它设成电脑上的主力全局翻译工具，这类反馈在不止一篇测评里能看到。

用起来顺不顺手主要看快捷键。Alt+Q 调出输入框，Alt+W 框选截图走 OCR，Alt+E 划词，习惯了基本不用切窗口。翻专业术语不准的时候切个引擎做对比，比对着一个结果猜要靠谱。OCR 支持中英混合，法德日这些语种也能认。

缺点也列出来：

- 虚拟商品，交付后不退款。先下免费版试，觉得不合适就别下单。
- 买断版不含云端同步，换电脑要重新配一遍翻译源和快捷键。
- 买断版只授权 1 台设备，多设备只能走订阅。
- 只有 Windows 和 macOS，Linux 和移动端没有。
- 译文质量取决于你选的翻译源，内置引擎翻专业内容未必准，得靠换源或者接 AI。
- 免费版额度很小，图片翻译每天 3 次，词典 10 次，重度用一天就见底。
- 换机和授权转移的规则，商品页没有明确说明。
